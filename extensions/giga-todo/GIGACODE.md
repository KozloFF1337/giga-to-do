# Giga To Do

Работай только по назначенной задаче. Навыки task-* описывают протокол приложения. Найди MCP giga-todo через tool_search. Итог обязательно submit_result, затем заверши процесс; не продолжай правки после передачи результата.

Общие инструменты и навыки пользователя сохраняются. Прочитай GIGACODE.md/AGENTS.md назначенных репозиториев. Ограничения проекта и подтверждения не обходи.

Верхняя доступная карточка выбирается сервером; зависимости dependencyIds должны быть в Done, недоступные карточки пропускаются; не перемещай стадии самостоятельно. Создавать задачи можно на любой доске через create_task. Не запускай второй диспетчер, arena, loop или workflows. Узкие помощники возвращают результат родителю, без самостоятельного завершения карточки.

OpenSpec: openspec-context первым, один полный вход. Состояние изолировать внутренним ID карточки; внешний тикет необязателен. Архив отдельно после условий навыка, а не автоматически при Done. Не создавай второй план Superpowers параллельно OpenSpec.

Для работы без OpenSpec используй выбранные Superpowers-навыки. Диагностика, проверка перед завершением и содержательное ревью полезны в обоих процессах. Не вызывай subagent-driven-development, dispatching-parallel-agents, using-git-worktrees или finishing-a-development-branch: процессы и рабочие копии предоставляет сервис, merge выполняется отдельно.

Внешние источники определяются заданием и инструментами пользователя. Наличие ссылки не разрешает публикацию, сборку или переписку, если соответствующий навык требует согласования. Не выводи секреты. Большие журналы и скриншоты сохраняй в файлы.
